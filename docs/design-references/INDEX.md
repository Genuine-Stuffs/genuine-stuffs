# Design References Index

Reference material (images, PDFs) used to guide AI Studio floor plan generation work.
See [`docs/roadmaps/ai_studio_roadmap.md`](../roadmaps/ai_studio_roadmap.md) for the
phase plan these usually map to, and `pdfs/AI_STUDIO_REBUILD_PLAN.pdf` for the current
authoritative execution spec (supersedes the roadmap's Phase 2 for the placement engine).

## pdfs/

| File | Describes | Relevant to |
| :--- | :--- | :--- |
| `AI_STUDIO_REBUILD_PLAN.pdf` | **Authoritative execution spec.** Master plan (v1.0) to replace the current `squarify`-based placement engine with a custom TypeScript backtracking constraint solver, fed by the existing Hive (Gemini 2.5 Flash) program generator, which is frozen/untouched. Defines locked architectural decisions, full data contracts (`types.ts`), a complete error taxonomy, and 8 sequential phases (0–7) each with files-touched, tasks, and a human-checked Definition of Done. Written explicitly to be handed to an AI session and followed literally. | All future floor-plan engine work — this is the spec to execute against, phase by phase. |
| `2026-10-02-solver-continuation-plan.md` | **Latest session handoff.** What shipped since Sep 22 (grid/harness fixes, MRV, solver-placed circulation, I8), current 20-seed pass rates, why hive-005's "UNSAT (proven)" is not a proof, and the ordered next steps. Supersedes `2026-09-22-solver-continuation-plan.md`. | Read first before any solver session. |
| `AI-Floor-Plan-Platform-Feasibility.pdf` | Strategic feasibility report: surveys the 2026 competitive landscape (Maket.ai, TestFit, etc.) and the five generation technique families (GANs, graph-conditioned, vector diffusion, LLM+structured-representation, prompt-guided editing). Identifies 5 hard problems — no Nigerian training data (biggest one), metric accuracy/buildability, surgical edit-by-prompt, NBC code compliance, and 2D→3D rendering. Recommends "Lane 1" (orchestrate existing techniques, don't train models yet) and argues Genuine Stuffs' structural edge is routing every generated plan into the material/supplier marketplace, not the generator itself. | Product strategy / sequencing. Explains *why* the rebuild plan chose a deterministic solver over an ML model: it solves the metric-accuracy and surgical-edit problems without needing the (currently nonexistent) Nigerian floor-plan dataset. |
| `Genuine Stuffs Ltd _ Africa's First AI-Native Construction OS.pdf` | Browser print-to-PDF of the **live** BOQ-Cal page (genuinestuffs.com/calculators, captured 2026-08-17), showing the existing "Neural QS v4.0" feature generating a 12-line-item, ₦13,429,000 Bill of Quantities from an uploaded floor plan image — specifically `Screenshot 2026-06-25 at 10.18.16 AM.png` from this same folder. | Evidence the BOQ generation half of the pipeline already works end-to-end against a real dimensioned plan; confirms the image-to-BOQ path is a solid foundation to build the new placement engine's output into. |
