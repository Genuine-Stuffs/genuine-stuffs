IMPLEMENTATION PLAN - Building Industry Transformation Platform

GOAL DESCRIPTION
Transform the existing "Material Insight Pros" website from a simple marketing/marketplace launchpad into a comprehensive Building Industry Transformation Platform. 
The goal is to move the "marketplace" aspect to a secondary feature and prioritize Industry Innovation tools: Technical Resources, Interactive Calculators, and Professional Portals.
The system will be restructured to be Mobile-First and support high-fidelity technical data (CAD/BIM) alongside standard e-commerce features.

USER REVIEW REQUIRED

Authentication Check: The "Professional Account Portal" feature implies user login. I will scaffold the UI for this at /pro-portal, but full Supabase Auth integration is assumed to be a separate or subsequent task unless existing auth is found.
